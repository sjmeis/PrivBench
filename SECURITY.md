# Security Policy

## Our Commitment to Privacy and Security

As a platform built to evaluate text privatization and data anonymization techniques, security is foundational to PrivBench. We take security vulnerabilities seriously and appreciate the community's help in identifying and reporting them responsibly.

---

## Supported Versions

We actively provide security patches and updates for the following versions of PrivBench:

| Version | Supported          |
| ------- | ------------------ |
| v1.X.x  | ✅ Actively Supported |

---

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.** Publicly disclosing a flaw before a patch is available puts deployments and users at risk.

If you discover a security vulnerability , please report it responsibly using one of the following methods:

1.  **GitHub Private Vulnerability Reporting:** Navigate to the **Security** tab of this repository, click on **Vulnerability reporting**, and select **Report a vulnerability**. This allows you to collaborate with us privately.
2.  **Private Email:** If you prefer, you can email us directly at [privbench@web.de].

### What to Include in Your Report:
To help us triage and patch the issue quickly, please include:
* A detailed description of the vulnerability and its potential impact.
* Clear, step-by-step instructions to reproduce the issue.

Thank you for helping keep PrivBench secure!
