# Contributing to PrivBench

First off, thank you for taking the time to contribute! Contributions from the community help make PrivBench a more robust, fair, and comprehensive evaluation platform for text privatization.

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

---

## How Can I Contribute?

### 1. Reporting Bugs
Before opening a new issue, please search the existing issues to see if it has already been reported. If it hasn't, open an issue and include:
*   A clear, descriptive title.
*   The exact step where the error occurs (e.g., Metadata step, Upload step, or during Evaluation).
*   Expected behavior vs. what actually happened.

### 2. Suggesting Benchmark Modules
If you want to suggest a new evaluation metric or privacy benchmark module:
1.  Open an Issue using the **Feature Request** template to discuss your idea.
2.  Ensure the metric can accept string lists (`List[str]`) for both original and privatized datasets.
3.  Specify whether your module requires an **GPU** or can run efficiently on a multi-threaded **CPU**.
4.  Follow the template of the current modules for guidance!
